Reads are closed until a lab token exists. Deliveries carry homeowner names, phones and addresses, and this repo is public, so the token has to be a Worker secret — never a committed var.

npx wrangler secret put ROOFLE_LAB_TOKEN --name jacbuildersfl
npx wrangler secret put ROOFLE_WEBHOOK_SECRET --name jacbuildersfl

The second one is optional: set it if Roofle lets you send a shared secret, and deliveries carrying it get marked verified. Storage is an ephemeral in-isolate buffer until a D1 database is bound — see ROOFLE.md for the one command that fixes that.
